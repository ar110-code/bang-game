# Roadmap

This roadmap focuses on maintainability and open-source collaboration while preserving existing game behavior.

## Near term

- Expand automated coverage around existing game-engine behavior.
- Document local development and multiplayer testing workflows.
- Review dependency updates regularly through Dependabot and CI.
- Improve issue and pull-request triage as community feedback arrives.

## Later

- Add focused regression tests for edge cases discovered through real usage.
- Document deployment and operational considerations for self-hosted instances.
- Review multiplayer security boundaries and authorization without changing game rules.

## Scope

Gameplay rules and existing behavior should remain unchanged unless a future change is explicitly proposed, reviewed, and documented.

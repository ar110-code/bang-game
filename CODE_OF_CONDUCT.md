# Contributor Covenant Code of Conduct

## Our pledge

We are committed to making participation in this project a respectful and constructive experience for everyone.

## Expected behavior

- Be respectful and professional.
- Focus criticism on ideas, code, and behavior rather than people.
- Accept constructive feedback.
- Respect different viewpoints and experiences.

## Unacceptable behavior

Harassment, personal attacks, discrimination, threats, and other abusive conduct are not acceptable.

## Enforcement

Report conduct concerns privately to the project maintainer through the security/contact channel described in `SECURITY.md`. Please do not disclose sensitive information publicly.

## Scope

This code of conduct applies to project spaces and interactions where participants are representing or contributing to the project.

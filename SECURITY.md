# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue.

Contact the repository maintainer privately through the GitHub repository owner's available contact channel and include:

- a clear description of the vulnerability;
- affected component or file;
- reproduction steps or proof of concept;
- potential impact;
- any suggested mitigation.

## Scope

Security-sensitive areas include the Socket.io server, room/game-state authorization, hidden-role and hidden-hand state sanitization, API routes, voice-chat functionality, and deployment configuration.

Do not include passwords, tokens, private keys, or other sensitive data in reports.

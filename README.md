# 🤠 بازی آنلاین وسترن بنگ (!BANG) — نسخه تحت وب بلادرنگ

[![Socket.io](https://img.shields.io/badge/Socket.io-4.8-white?style=for-the-badge&logo=socket.io)](https://socket.io/)

پیاده‌سازی مدرن، کامل و بلادرنگ بازی فکری و کارتی محبوب جهانی **«غرب وحشی» (!BANG)** به زبان فارسی و با هوش مصنوعی ربات‌ها (Bots)، انیمیشن‌های نرم، صداگذاری وسترن و رابط کاربری واکنش‌گرا برای موبایل و کامپیوتر.

---

## 🌟 ویژگی‌های کلیدی (Features)

- 🎮 **مولتی‌پلیر آنلاین و ربات‌های هوشمند:** امکان بازی همزمان با دوستان به همراه ربات‌های خودکار با منطق استنتاجی و تصمیم‌گیری استراتژیک.
- 📜 **آرت اختصاصی کارت‌ها و کاراکترها:** بیش از ۴۵ تصویرسازی وسترن به نسبت استاندارد ۲ در ۳ برای تمام کارت‌های بازی، نقش‌ها و کاراکترها.
- 🕵️ **سیستم نقش‌های مخفی:**
  - 🌟 **کلانتر (Sheriff):** حفظ نظم و نابودی یاغی‌ها و خائن.
  - 🎖️ **معاون (Deputy):** محافظت از کلانتر و دفاع از قانون.
  - 💀 **یاغی‌ها (Outlaws):** سوءقصد و نابودی کلانتر شهر.
  - 🐍 **خائن (Renegade):** بقا تا دوئل تک‌به‌تک پایانی با کلانتر!
- ⚡ **توانایی ویژه ۱۶ کاراکتر اورجینال:**
  - بارت کسیدی، بلک جک، کالامیتی جنت، ال گرینگو، جسی جونز، جوردونایس، کیت کارلسون، لاکی دوک، پاول رگرت، پدرو رامیرز، رز دولان، سید کچام، اسلب د کیلر، سوزی لافایت، والچر سم، ویلی د کید.
- 🎯 **محاسبه دقیق فواصل و برد اسلحه‌ها:** پشتیبانی از اسب‌های موستانگ (+۱ فاصله)، آپالوزا (-۱ فاصله)، شلیک‌های برد ۱ تا ۵ و بشکه‌های دفاعی.
- 🏪 **رویدادهای گروهی وست:** فروشگاه بزرگ (General Store)، دلیجان، ولز فارگو، دینامیت چرخشی، حمله سرخ‌پوست‌ها، رگبار مسلسل گاتلینگ و دوئل‌های تن‌به‌تن.
- 📜 **وقایع‌نگار هوشمند (Game Log):**
  - فیلتر وقایع بر اساس تک‌تک بازیکنان («فقط کارهای من»).
  - خطوط جداکننده جذاب وسترن بین نوبت‌ها.
- 🔊 **موتور صوتی وسترن (Sound FX):** افکت‌های شلیک گلوله، نوشیدن، دینامیت، ورق زدن و زپلشک.
- 📱 **طراحی کاملاً واکنش‌گرا (Responsive):** بهینه‌سازی دقیق میز و صندلی‌ها برای صفحه گوشی بدون هم‌پوشانی.

## 🚀 راهنمای نصب و اجرای محلی (Quick Start)

### ۱. کلون کردن مخزن:
```bash
git clone https://github.com/ar110-code/bang-game.git
cd bang-game
```

### ۲. نصب پکیج‌ها:
```bash
npm install
```

### ۳. اجرا در حالت توسعه (Dev):
```bash
npm run dev
```
سپس آدرس [http://localhost:3000](http://localhost:3000) را در مرورگر باز کنید.

### ۴. بیلد و اجرای نسخه نهایی پرسرعت (Production):
```bash
npm run build
npm start
```
سرور روی پورت `3005` آماده پذیرایی از بازیکنان خواهد بود.

## 🛠️ ساختار معماری پروژه (Architecture)

```
bang-game/
├── public/
│   ├── assets/
│   │   ├── cards/         # کارت‌های بازی وسترن (۲:۳)
│   │   ├── characters/    # آرت کاراکترها
│   │   └── roles/         # کارت‌های نقش مخفی
│   └── favicon.svg        # نشان ستاره کلانتری وکتور
├── src/
│   ├── app/
│   │   ├── page.tsx       # صفحه لابی، ورود و انتخاب نام
│   │   └── room/[roomId]/ # صفحه اصلی سالن بازی و میز
│   ├── components/
│   │   ├── game/          # کامپوننت‌های میز، کارت‌ها، لاگ و مودال‌ها
│   │   └── ui/            # آیکون‌ها، نشان‌ها و تیرهای جان
│   └── lib/
│       ├── game-engine/   # موتور هسته بازی (اکشن‌ها، دک، قوانین و بات‌ها)
│       ├── socket/        # هندلرهای سرور و کلاینت Socket.io
│       └── sound/         # افکت‌های صوتی
├── server.ts              # سرور ترکیبی Next.js + Socket.io
└── tailwind.config.ts     # رنگ‌بندی سالن وسترن و فونت‌ها
```
